# 個管員 AA 績效考核工具說明書

## 一、背景說明

### 1.1 為什麼需要這套考核

在長照 2.0 體系中，**個案管理員（個管員）**負責個案的收案評估、照護計畫擬定、服務連結與追蹤。個管員的績效表現直接影響：

- 個案服務品質與照護連續性
- 服務案件量的穩定成長
- 機構整體服務量能與營運績效

過去個管員的績效多仰賴主管主觀印象或事後補記，容易產生：
- 評分標準因人而異，同仁難以信服
- 缺乏客觀數據佐證，難以作為獎懲依據
- 考核紀錄散落各處，不易追蹤比對

因此，本工具以「**每月案件達成率 + 每半年綜合評估**」雙軌並行，建立一套**可量測、可比較、可追溯**的個管員考核機制。

### 1.2 考核對象

本工具適用於機構內**個管員層級**人員（受評對象：林婉雯、陳燕惠、吳佩慈、張怡如、李芷涵）。

### 1.3 考核週期

- **評分期間**：每 6 個月為一期（例如 1-6 月、7-12 月）
- **考核頻率**：約每六個月考核一次
- 第 1 至第 6 月依序個別評分，期末彙總計分

---

## 二、考核架構總覽

考核分為三大面向，權重與架構如下：

| 面向 | 內容 | 題數 | 每期涵蓋 |
|------|------|------|----------|
| AA01 達成率 | 個管員主要案件服務達成情形 | 6 題（每月 1 題） | 6 個月 |
| AA02 達成率 | 個管員協助/超案服務達成情形 | 6 題（每月 1 題） | 6 個月 |
| 綜合評估 | 跨專業會議、客訴、配合度、溝通、專業知能 | 6 題 | 1 次 |
| 補充加/扣分 | 各期特殊表現之加減分 | 1 欄 | 1 次 |

## 三、評分規則（依達成率）

### 3.1 評分符號與分數對照

| 符號 | 對應分數 | 意義 |
|------|----------|------|
| ++ | +2 | 優異 |
| + | +1 | 良好 |
| 無 | 0 | 普通 |
| - | -1 | 達標但待加強 |
| -- | -2 | 嚴重不足 |

### 3.2 AA01／AA02 達成率評分標準（機構現行標準）

達成率以每月結算之案件數相對於目標案件數計算：

```
達成率 = 當月實際案件數 ÷ 當月目標案件數 × 100%
```

| 達成率 | 評分 | 說明 |
|--------|------|------|
| 95% 以上 | ++ | 超標達成，表現優異 |
| 90% - 94% | + | 穩定達成 |
| 85% - 89% | - | 達成但尚有差距，需留意 |
| 80% - 84% | -- | 低於水準，需列入輔導 |

> ✅ 依機構現行 config 標準：`95%以上++、90-94%+、85-89%以上-、80-84%--`

### 3.3 AA01、AA02 之定義

| 代碼 | 評核重點 | 實際項目 |
|------|----------|----------|
| **AA01** | 個管員主要案件管理 | 收案評估、照護計畫、每月追蹤之案件量達成 |
| **AA02** | 協助案件／超案服務 | 協助連結、支援服務件數達成情形 |

### 3.4 綜合評估項目評分標準

| 項目 | 評分標準 |
|------|----------|
| 辦理跨專業討論會議 | 完成 → +；無須辦理 → 無；未完成 → - |
| 辦理區域聯繫會議 | 完成 → +；無須辦理 → 無；未完成 → - |
| 表揚及客訴（須說明） | 獲表揚 → + 或 ++（依情節）；一般 → 無；客訴 → - 或 --（依情節） |
| 工作配合度 | 良好 → ++；合格 → +；待加強 → -；不理想 → -- |
| 溝通協調能力 | 良好 → ++；合格 → +；待加強 → -；不理想 → -- |
| 專業知能 | 良好 → ++；合格 → +；待加強 → -；不理想 → -- |

### 3.5 補充加/扣分

- 用於記錄各期**特殊事項**（重大貢獻、破格表現、重大疏失）
- 由主管依事實填報，可為整數加/扣分
- 每一分皆應於備註欄位說明原因

## 四、總分計算方式

### 4.1 計算公式

```
AA01 小計   = Σ（第1~6月 AA01 評分分數）
AA02 小計   = Σ（第1~6月 AA02 評分分數）
綜合評估小計 = Σ（6 項綜合評估評分分數）

─────────────────────────────────────────
考核總分 = AA01小計 + AA02小計 + 綜合評估小計 + 補充加/扣分
```

### 4.2 計算範例（假設例）

| 項目 | 每月評分串 | 小計 |
|------|-----------|------|
| AA01（6 月） | ++、+、++、-、+、++ | 2+1+2-1+1+2 = **7** |
| AA02（6 月） | +、+、無、+、+、+ | 1+1+0+1+1+1 = **5** |
| 綜合評估（6 項） | ++、+、+、++、+、+ | 2+1+1+2+1+1 = **8** |
| 補充加/扣分 | +3 | **+3** |
| **考核總分** | | **23** |

## 五、績效等第與後續運用

### 5.1 績效等第建議對照

> 以下級距為建議值，實際級距與比例可依機構政策滾動調整。

| 總分範圍 | 建議等第 | 管理處置建議 |
|----------|----------|--------------|
| 15 分以上 | 優等 | 建議列入績效獎金最高級、優先升遷/調薪人選 |
| 8 - 14 分 | 甲等 | 績效符合期待，予以獎勵 |
| 0 - 7 分 | 乙等 | 加強輔導，訂定改善計畫並追蹤 |
| -1 至 -7 分 | 丙等 | 需月月列管，安排督導會談 |
| -8 分以下 | 丁等 | 啟動深度輔導，評估職務調整 |

### 5.2 考核結果的四大用途

| 用途 | 運用方式 |
|------|----------|
| **績效獎金** | 依等第對應獎金級距，優等者領取最高獎金 |
| **升遷調薪** | 連續兩期優等者，列為升遷/調薪優先對象 |
| **考績等第** | 作為年度考績優/甲/乙等之客觀依據 |
| **內部回饋** | 提供個管員具體改善方向，促進專業成長 |

## 六、主管操作流程（SOP）

### 6.1 評核前準備

1. 確認受評個管員之**當期（6 個月）案件數據**
2. 依機構每月統計之達成率，預先整理 12 項（AA01、AA02）評分
3. 蒐集期內**表揚/客訴紀錄、會議辦理紀錄**，供綜合評估參考

### 6.2 系統操作步驟

1. **登入**：輸入主管密碼
2. **填寫基本資料**：
   - 考核人姓名
   - 考核週期（例：2026 H1）
   - 考核月份（例：1,2,3,4,5,6月）
   - 受評對象（選擇個管員）
3. **逐月評分**：AA01 6 題 → AA02 6 題 → 綜合評估 6 題
   - 直接在 ++ / + / 無 / - / -- 五選一點選
4. **補充加/扣分**：依需填寫（無則為 0）
5. **計算考核結果**：系統自動加總並顯示各面向分數與總分
6. **列印存檔**：輸出紙本，主管簽名後歸檔

### 6.3 評分注意事項

- 達成率評分**以客觀數據為準**，主管不需另行臆測
- 綜合評估應**平時即時記錄**，避免期末記憶失真
- 表揚及客訴欄位如填寫非「無」，須在備註「須說明」欄位交代事由
- 考核結果應於個別會談時告知受評者，雙向溝通

## 八、常見問題（FAQ）

### Q1：達成率數據從哪裡來？
A：由機構每月結算之案件數量統計得出，主管於評核前向行政管理單位索取當期 6 個月數據。

### Q2：評分可以修改嗎？
A：可。結算後如發現誤填，重新點選該題評分再按「計算考核結果」即可更新。

### Q3：綜合評估的「無須辦理」是什麼意思？
A：指當期無辦理該會議之需求（如無新案需跨專業討論），此時應評「無」而非「-」。

### Q4：補充加/扣分最多能填多少？
A：無硬性上限，但建議每分皆有客觀事證，並於備註說明。

### Q5：這個工具能在多台電腦用嗎？
A：可。部署到 GitHub Pages 之後，任何有網路的裝置開啟同一網址即可使用，無需安裝。

### Q6：密碼可以直接寫在網頁裡，安全嗎？
A：本工具適用**機構內部主管**使用情境。若需更高安全需求，可升級為雲端資料庫＋後端認證版本。
