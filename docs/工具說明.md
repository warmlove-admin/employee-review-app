# 個管員 AA 績效考核工具說明

## 一、工具核心概念

本工具專為**長照居家服務機構**設計，用於評核**個案管理員（個管員）**執行 AA01、AA02 服務代碼的績效表現。

### 為什麼需要這個工具？

| 傳統方式的問題 | 本工具的解決方案 |
|----------------|------------------|
| Excel 手動計算，容易出錯 | 系統自動計算評分 |
| 評分標準不一致 | 標準化評分選項（++ / + / 無 / - / --） |
| 缺乏紀錄保存 | 每次考核自動存檔 |
| 無法快速查詢歷史 | 雲端儲存，隨時查閱 |
| 跨裝置使用困難 | 純網頁版，手機/平板/電腦皆可使用 |

---

## 二、評核項目說明

### 2.1 AA01 達成率（個管員主要服務指標）

AA01 代表個管員執行的**居家服務案件數達成率**，評核週期為半年（6個月）。

| 評分標準 | 顏色標示 |
|----------|----------|
| **++**（優異） | 達成率 95% 以上 |
| **+**（良好） | 達成率 90-94% |
| **無**（普通） | 達成率 85-89% |
| **-**（待改善） | 達成率 80-84% |
| **--**（不佳） | 達成率 80% 以下 |

**計算方式：**
- 每月個別評分，6個月加總計算合計分數
- AA01 達成率 = 實際服務案件數 ÷ 目標案件數 × 100%

### 2.2 AA02 達成率（協助服務指標）

AA02 代表個管員**協助居服員執行服務的案件數達成率**，同樣評核6個月。

評分標準與 AA01 相同。

### 2.3 綜合評估項目

| 項目 | 說明 | 評分標準 |
|------|------|----------|
| 辦理跨專業討論會議 | 個管員是否定期召開跨專業團隊會議 | 完成 +、無須辦理 x、未完成 - |
| 辦理區域聯繫會議 | 與其他單位的協調會議 | 完成 +、無須辦理 x、未完成 - |
| 表揚及客訴 | 客戶表揚或投訴紀錄 | 獲表揚 + 或 ++、無 x、客訴 - 或 -- |
| 工作配合度 | 與團隊成員的協作表現 | 良好 ++、合格 +、待加強 -、不理想 -- |
| 溝通協調能力 | 與個案、家屬、團隊的溝通 | 良好 ++、合格 +、待加強 -、不理想 -- |
| 專業知能 | 專業知識與技能運用 | 良好 ++、合格 +、待加強 -、不理想 -- |

## 三、計算方式

### 3.1 評分轉換

| 符號 | 分數 | 意義 |
|------|------|------|
| ++ | +2 | 優異 |
| + | +1 | 良好 |
| 無 | 0 | 普通 |
| - | -1 | 待改善 |
| -- | -2 | 不佳 |

### 3.2 總分計算

```
AA01 總分 = Σ(各月AA01評分分數)
AA02 總分 = Σ(各月AA02評分分數)
綜合評估總分 = Σ(各項目評分分數)

最終得分 = AA01總分 + AA02總分 + 綜合評估總分 + 補充加/扣分
```

### 3.3 績效等級建議

| 總分範圍 | 建議等級 | 說明 |
|----------|----------|------|
| 15分以上 | 優等 | 績效卓越，建議獎勵 |
| 8-14分 | 甲等 | 績效良好，符合期待 |
| 0-7分 | 乙等 | 績效普通，需加強輔導 |
| -1至-7分 | 丙等 | 績效待改善，需制定改善計畫 |
| -8分以下 | 丁等 | 績效不佳，需深度輔導或調整職務 |

## 四、主要解決的問題

### 4.1 個案管理員績效評估困難

**問題：** 個管員的工作涵蓋面廣，難以量化評估。

**解決方案：** 
- 將工作拆分為 AA01（主要服務）、AA02（協助服務）、綜合評估三大面向
- 使用標準化評分，確保評估一致性

### 4.2 服務達成率追蹤不易

**問題：** 個管員每月服務案件數難以快速掌握達成狀況。

**解決方案：**
- 每月追蹤 AA01、AA02 達成率
- 半年累計評分，一目瞭然

### 4.3 評核紀錄保存困難

**問題：** 傳統紙本或 Excel 容易遺失，查詢不便。

**解決方案：**
- 雲端儲存所有考核紀錄
- 支援列印功能，可輸出紙本備查

### 4.4 跨裝置使用需求

**問題：** 主管可能在辦公室、外出或居家時需要進行考核。

**解決方案：**
- 純 HTML 網頁版，任何裝置皆可使用
- 無需安裝軟體，開啟瀏覽器即可操作

## 六、使用流程

### 6.1 主管操作流程

1. **登入系統**：輸入主管密碼（91166964）
2. **填寫基本資料**：考核人、受評者、考核週期、月份
3. **進行評分**：依序完成 AA01、AA02、綜合評估項目評分
4. **計算結果**：系統自動計算總分
5. **列印存檔**：可列印紙本備查

### 6.2 評分注意事項

- AA01、AA02 達成率需事先統計實際數據
- 綜合評估項目需參考日常觀察紀錄
- 補充加/扣分欄位用於記錄特殊事項

## 八、常見問題

### Q1: 如何部署到網路上供多人使用？
A: 可使用 GitHub Pages 免費託管，或部署到公司內部伺服器。

### Q2: 資料是否安全？
A: 目前資料儲存在使用者瀏覽器本地，建議搭配其他備份機制。

### Q3: 可以修改評分項目嗎？
A: 可以，直接編輯 HTML 檔案中的設定即可。

### Q4: 如何匯出考核紀錄？
A: 目前支援列印功能，未來可擴充匯出 Excel 或 PDF 功能。
