主管操作 SOP

五步完成一次考核

  1. 登入 輸入主管密碼
  2. 填寫基本資料 考核人、週期、月份、受評對象
  3. 逐項評分 AA01×6 → AA02×6 → 綜合評估×6，點選即可
  4. 補充加/扣分＋計算 系統自動加總總分
  5. 列印存檔 輸出紙本簽名歸檔
