# 沃恩員工考核平台

個管員 AA 績效考核工具，專為長照居家服務機構設計。

## 功能特色

- 主管密碼登入保護
- AA01/AA02 達成率評分（每月底分）
- 綜合評估項目（跨專業會議、工作配合度、溝通協調、專業知能）
- 自動計算考核總分
- 響應式設計（手機/平板/電腦）
- 列印功能

## 使用方式

1. 直接在瀏覽器開啟 `index.html`
2. 或部署到 GitHub Pages 取得免費網址

## 評分選項

| 符號 | 分數 | 意義 |
|------|------|------|
| ++ | +2 | 優異 |
| + | +1 | 良好 |
| 無 | 0 | 普通 |
| - | -1 | 待改善 |
| -- | -2 | 不佳 |
